# Portfolio

Personal portfolio website built with React + Vite + Tailwind CSS.

## Features

- Responsive design
- Dark/Light theme toggle
- Smooth animations with Framer Motion
- Typewriter effect
- Project showcase with image placeholders

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Deploy to Vercel by connecting the GitHub repository.
